# Shiny integration changes

Edited files:
- scripts_DoNotTouch/Shiny/app_server.R
- scripts_DoNotTouch/Shiny/run_rnaseq_results_explorer.sh
- scripts_DoNotTouch/Shiny/sbatch_rnaseq_results_explorer.sh
- scripts_DoNotTouch/Shiny/README.md
- scripts_DoNotTouch/Shiny/CHANGES_2026-04-08.md
- scripts_DoNotTouch/config.py
- scripts_DoNotTouch/bulkRNAseq.py
- bulkRNAseq/bulkRNAseq.ipynb

What changed from the start:
- Added a Shiny app bundle that reads directly from completed CodeSpringLab results on the server.
- Added launcher scripts that load the same R module style used elsewhere in the pipeline.
- Made the launcher resolve the config path to an absolute path so Shiny does not lose the config after startup.
- Made the Shiny app honor both `data_dir` and `design_matrix_path` from the config file.
- Added `results_directory` to the default config template and preserved it when `config.py` gets rewritten.
- Made `bulkRNAseq.py` tolerant when `results_directory` is initially missing.
- Added `csl.shiny_Prep()` to write a per-project Shiny config into `csl_results/<project>/shiny/`.
- Changed `csl.shiny_Prep()` to always ask for the completed data folder and the design matrix path.
- Changed `csl.shiny_Prep()` to print copy-ready server launch and local SSH tunnel commands.
- Added a notebook section at the end of `bulkRNAseq.ipynb` for the Shiny launch step.
